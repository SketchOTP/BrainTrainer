# Public repository contents

This branch contains the active source candidate, authored design and research notes, focused tests, and the creature sprite artwork used by the project. The root MIT license applies to project source and documentation only where the project owns the relevant rights; it does not relicense external or owner-supplied art.

The following local material remains outside this public repository:

- Live companion checkpoints, personal event history, reflection transcripts, and runtime service state.
- Validation directories and generated experiment outputs.
- Recovered game executables, brain/genome dumps, native captures, and private research inputs.
- The Porymap project, ROM-derived Littleroot layouts, extracted map graphics, and other upstream game assets.
- Local machine paths, LAN/Tailscale endpoints, and generation workspace paths.

The included sprite sheets are the owner-supplied and generated project artwork recorded in `examples/persistent_individual/assets/creature/`. The duplicate ZIP bundle and local source paths are omitted. Their rights are separate from the code license.

Many historical tests require private brain data, local checkpoints, or ROM-derived fixtures. This branch includes only test files whose source and intra-test imports do not depend on those omitted paths. The included tests have not been run for this publication; no test result is implied.
