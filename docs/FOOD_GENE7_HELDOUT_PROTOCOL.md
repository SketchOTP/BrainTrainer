# Proposed held-out protocol: persistent gene-7 state

This protocol is a draft until the development tract-transfer and reversal investigations and independent continuation replays have been recorded and a machine-readable manifest is frozen. It tests the contribution of retaining gene-7 drive-to-combination tract state under the experimental in-contact lifecycle. The scoped freeze executes transient tract computation but discards its persistent state. It is not a whole-brain learning-disabled control or a claim of native action parity.

Use fresh seeds 56–95 for each embodiment; these seeds were reserved and have not been used in the preceding development investigation. Pair ordinary and scoped-freeze conditions at the same seed, walking or swimming body, each of two mirrored layouts, and each of two food-value assignments. Both conditions receive the feedback caused by their own actual interactions. They start from matching full experiment state except the explicit control marker. Differences in their later experiences are part of the treatment effect, and limit conclusions about which representation carries value.

Use the prior calibrated 32-tick limit per opportunity and four phases of 20 opportunities: initial experience, initial evaluation, reversed-value experience, reversal evaluation. Reverse food effects at the phase boundary. No host policy selects an action or target, and each failure or non-completion is unsuccessful in the primary score. Record choices, attempted and carried-out actions, targets, outcome, connection state and weak queues; checkpoint continuation and matched-needs/unmodified-needs one-tick probes at the original boundaries. Probe clones clear pending outcome feedback and do not deliver a new outcome. Preserve full observations and report the intervention; retained neuron activity and chemistry other than the explicitly matched need remain a limitation.

For each body and each evaluation phase, first average the four mirrored/outcome-assignment branch scores within each seed and condition. The primary estimate is ordinary minus frozen mean successful-choice proportion across the 40 paired seeds. Compute deterministic paired-seed percentile bootstrap 95% intervals with 10,000 resamples and seed 20261106. The predeclared capability target is a difference of at least +10 percentage points and a 95% interval entirely above zero for both initial and reversal evaluation in each body. Each body and phase is reported separately; the overall milestone passes only if all four meet the threshold. This conjunctive decision requires all four tests to pass; do not pool branches as independent seeds. Report estimates and intervals even when the target fails.

Report completed-consumption and target/action counts, secondary conditional-on-consumption preference, phase learning curves, reversal, matched/unmodified-needs probes, seed variation and non-completion. Report elapsed time, summed worker CPU and measurement scope for memory. Verify full paired starting checkpoints apart from the expected control marker, persistent gene-7 state, all expected case keys and checkpoint continuation. Hash program, runner, analysis, protocol, source and each raw file before analysis. Retain data and identify any interrupted/resumed batches. This protocol does not claim that tract state alone encodes food value; controlled tract-transfer experiments address that narrower question separately.
