# Recovery investigation qualification

Prospective panel: seeds 131–134, each with a v7 control and v8 candidate, and
both restored-recovery and persistently broken recovery conditions. Start a switch
learning goal, then externally reduce reserve to .03 and rest rate to zero. Run
40 actual ticks; in the repair condition set the rate to .5 after tick index 16,
without changing reserve. This intervention must not count as demonstrated repair
by the creature. All records retain actual source attribution.

Candidate gates: request help once from three observed failed rests; hold without
spending reserve between probes; do not claim recovery in the broken condition;
in the repaired condition observe positive recovery, complete maintenance, then
finish the original learning goal. Restoration during investigation must preserve
future actions and review. Compare actual outcomes against v7, without requiring
that control fail by assertion. Preserve traces and failed gates.

This evaluates an authored investigation strategy and grounded help request, not
self-repair, general diagnosis, learned probe timing or improved improvement.
