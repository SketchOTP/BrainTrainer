# Assisted learning protocol, v1

Freeze before prospective seeds 91–94. Each case hides food and presents an
opaque device needing four presses per visible change. Contact geometry
alternates. After three presses with no effect, ordinary activity must emit one
grounded assistance request with its actual evidence, without diagnosing a code
fault. A checkpoint is restored, then an attributed teacher suggests five more
attempts. Advice must remain unverified and must not advance time, mutate the
world, or increase experienced effect counts. Five actual attempts must produce
two observed changes and support the advice only in that context.

Transfer: hide the first object and present a new identity with the same type and
function. Explicit test forks compare intact retained practice knowledge with a
projection ablation that removes only `retained_practice` from learned skills.
Record that experimental control. Both retain all actual experience and all other
skill knowledge. Intact memory must verify the effect on the fourth attempt;
ablated memory must stop after three. Test forks never become the parent.

Each seed also meets an inert object and gets the same advice. It must stop after
eight total attempts, mark the advice unsupported, and retain no successful
practice lesson. No executable change is warranted solely from lack of effect.

Retain complete checkpoints and reports. This establishes a bounded teaching
interaction with causal behavioral memory, not person recognition, trust,
attachment or sustained relationship quality. Teacher identity is supplied
metadata, not inferred recognition. The authored advice interface supports only
a limited extension of an existing requested practice goal.
