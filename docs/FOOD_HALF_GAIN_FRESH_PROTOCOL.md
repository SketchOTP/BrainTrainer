# Fresh-seed test of half-strength worsening feedback

This protocol evaluates one fixed candidate selected from the earlier four-seed development diagnostics: multiply an already-attributed positive hunger-training input by 0.5 while keeping negative inputs, actual outcomes, chemistry, target selection and the recovered neural kernel unchanged. The gain is active from the beginning in all phases; it receives no phase indicator or hidden food values. The baseline uses the ordinary recovered-brain lifecycle. This is a host-interface extension, not native Docking Station behavior or a whole-brain learning-disabled control.

Before any cases execute, freeze this protocol, the runner, program, source digests and the selected earlier development result. Use seeds 96–111, which are outside previously documented development seeds 0–15 and the completed held-out seeds 56–95. This is a fresh test of this candidate, but is still a narrow benchmark: two food categories, the experimental in-contact lifecycle and two simple embodiments. Run both bodies, both mirrored layouts and both food-value assignments for each seed, paired between baseline and gain 0.5. This produces 256 cases; within each body and condition there are 64 correlated branches drawn from 16 seeds.

Each case has four phases of 20 opportunities: initial experience, initial evaluation, reversal experience and reversal evaluation. Values reverse at the start of reversal experience. Each opportunity has a 32-tick limit. A non-choice or failed interaction is unsuccessful in the primary per-opportunity score. Record observations, choice, executed action, target, outcomes and each phase-boundary gene-7 tract state. Record all pending outcomes and the corresponding phase of delivery, plus independent case timing and memory scope. No action or target is forced, and assignment and geometry are counterbalanced within each seed.

At the end of the first and reversal experience phases, test both matched-needs and unmodified-needs retention probes on independent JSON checkpoint clones. Fix the same in-contact geometry and remove pending outcome feedback in the probe clone only; execute one brain tick without delivering a new outcome or performing the chosen action. For matched needs set energy 0.5, hunger and chemical 150 to 0.8; leave other neuron, chemistry and RNG state as retained. Restore a second clone from the same JSON checkpoint and require an identical probe result and post-probe brain state. The retention endpoint is the probability of choosing eat while attending the then-higher-value target; it is a controlled observation and leaves residual neural state, so cannot alone prove a stored association.

Also checkpoint every case after opportunity 40, restore the correct experiment class through JSON and run both original and restored instances to completion. Require identical subsequent observations, choices, outcomes, pending events, RNG, full brain state, tract and weak queues. Compare initial full snapshots for each pair after removing only the candidate's gain marker, and check first choice and observation. A mismatch or missing case invalidates the comparison. Existing attribution checks reject outcomes mismatched to actions or targets; unrelated or misleading feedback must not be injected into the primary experiment.

## Analysis fixed before collection

Average each seed's four mirror/assignment branch rates, then calculate gain-minus-baseline mean differences across the 16 paired seeds, separately by body. Use 10,000 paired seed bootstrap resamples, random seed 20261107 and percentile 95% intervals. Do not pool the four branches as independent seeds. Report every phase, non-completion, completion, conditional-on-completion success and time to first newly good consumption with censored failures. Record per-opportunity learning curves and per-seed differences.

For this fresh, narrowly scoped follow-up, define a *candidate capability target* before running: in each body, reversal-experience success improves by at least 5 percentage points with its interval entirely above zero; reversal-evaluation and initial-evaluation scores each have a mean at or above baseline and an interval lower bound greater than −5 points; and the matched-needs post-reversal retention endpoint also has a mean at or above baseline with an interval lower bound greater than −5 points. All four criteria must hold for both bodies for the candidate to meet this target. Report the actual results and uncertainty even if it fails. This practical non-inferiority margin is an operational decision, not proof that no individual behavior was harmed; no claim of native parity follows.

Keep the prior held-out analysis unchanged. Do not tune the gain on these fresh cases. A failed or inconclusive test must be reported rather than changing the score, excluding failures or selecting another controller after seeing the results.
