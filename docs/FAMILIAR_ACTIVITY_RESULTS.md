# Retained experience shapes voluntary familiar activity

All eight prospective histories (seeds 121–124, two contrasting histories each)
passed the [frozen protocol](FAMILIAR_ACTIVITY_PROTOCOL.md). With the same currently
available objects, the creature chose to revisit the object previously observed
to respond more reliably. Training order and approach side alternated. Choices
were followed by actual executed interactions, not just preference reports.

After that preferred object became inert without changing its type label, every
history recorded failed revisits and eventually chose the alternative within
180 ordinary ticks. Full histories, the evidence rankings supporting the first
choice and later choices remain in `validation/familiar-activity-v1/`.

This is a bounded history-shaped activity tendency. It supplies voluntary return
to familiar activities and revision when old expectations stop working. The
preference for visible responsiveness, eight-outcome evidence window and 32-tick
spacing are authored initial mechanisms. Experience supplies the rankings. No
emotion, enjoyment, attachment or complete personality is established.
