# Experimental body action lifecycle

`LifecycleFoodExperiment` adds a body-layer executor for the brain's selected action; it does not rank foods or provide a policy. It is opt-in and leaves the original benchmark, recovered brain, checkpoints and prior results intact. A separate `LifecycleDriveCombFrozenExperiment` uses the same executor and the scoped gene-7 persistent-state freeze.

When the brain selects eat with an available target, the body starts a pending action recording the original action ID and target. If not in contact it advances one body movement step toward that target per tick. On a subsequent contact tick it records contact; on a later tick it consumes if contact still holds. It credits the completed outcome to the original action ID and target. This execution does not issue a preferred choice to the brain.

The brain continues to select an action each tick. A different action interrupts the pending eat and is executed; a new explicit eat target interrupts and starts an action for the new target. An eat choice with no target does not by itself replace the remembered target. A missing target or unavailable eat fails the action; an opportunity timeout cancels it. If contact is lost before consumption the executor returns to approach. Each record distinguishes the current brain choice from the carried-out action and lifecycle events. These cancellation, timing and contact rules are experimental design choices, not established native parity.

The [isolated native follow-up](../research/docking-station-20261103/brain-connections-20261106/approach-touch-followup/REPORT.md) observed a cue-assisted brain-selected eat persist through a moving `APPR` interval, followed by moving `TOUC` and a food event for the selected target. A separately injected competing script replaced an in-progress eat script; it did not demonstrate a changed brain decision. The experiment does not establish that decision changes interrupt the native script, or that Boolean contact, movement rates or timeout in this adapter match native behavior.

The snapshot stores the pending original action and its stage, alongside the ordinary brain, world, RNG and pending feedback. `save_research_checkpoint` and `restore_research_checkpoint` wrap snapshots in a type-tagged portable envelope and reject unknown types or inconsistent control/lifecycle tags. They restore the correct optional body rule or scoped control after a JSON round trip. Legacy bare snapshots remain compatible and unchanged; callers must use the corresponding exact experiment class to restore them. In particular, passing a bare controlled snapshot to the ordinary legacy loader can silently drop the control, and an old approach-probe snapshot does not itself identify the body rule. Use the typed envelope for new experiments.

The original in-contact 16-tick development calibration applied to the previous immediate-contact adapter. In the separate [twenty-opportunity lifecycle calibration](../runs/food-qualification/lifecycle-twenty-calibration-v1.json), 32 ticks was the shortest tested budget to reach the preregistered 13/16 seeds in every body/mirror/control cell: all 32-tick cells reached 15/16 or 16/16. At 16 ticks the non-mirrored cells reached only 12/16. This is a development timing qualification for the in-contact task and experimental interruption rule, not a learning result or an embodied movement qualification. The previous combined benchmark's failure remains recorded. The 640-case run used about 422 seconds wall and 2471 summed worker CPU seconds, with 6 workers; maximum cumulative per-worker peak RSS is in the artifact and is not total process-family memory. Confirmatory seeds remain reserved.

`probe_retained_choice` implements the proposed single-tick retention probe on a typed checkpoint clone at an action boundary. It removes pending feedback only in the clone, fixes both foods in contact at mirrored positions and executes no action or outcome. In the matched-needs variant it sets energy, hunger and chemical 150 to 0.5, 0.8 and 0.8; an unmodified-needs variant exposes sensitivity to that intervention. Other neural state, chemistry and RNG remain intact. The appropriate gene-7 control is applied to its probe tick. These interventions and residual activity limit interpretation: a changed choice alone does not prove a stored food association. The training continuation is unchanged.

A [one-seed plumbing smoke](../runs/food-qualification/lifecycle-gene7-smoke-v1.json) ran 16 combinations of embodiment, mirror, food-value assignment and ordinary/scoped-freeze condition, with two opportunities per phase and an eight-tick limit. Both retention variants ran at both phase boundaries. All eight frozen cases retained the initial gene-7 tract state. The full histories and post-probe brain states are retained beside the summary. This tiny smoke checks execution and instrumentation, not preference or reversal learning, and its eight-tick duration is not the qualified protocol.
