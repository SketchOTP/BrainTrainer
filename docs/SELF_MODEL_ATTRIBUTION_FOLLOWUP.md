# Motor action attribution follow-up

The original 12-seed study stored the current brain choice ID as the motor sub-attempt ID. A later audit found 288 of 12,737 cases in which the inherited execution lifecycle was continuing an earlier eat action, so the original lifecycle action ID differed despite the target matching. The original study, its raw data and summary remain unchanged. The exact frozen runner is archived as `runs/self-model/frozen-motor-benchmark.py`, SHA-256 `76bb147f0aefd2620485c52ddd2bee1d9c6c434c03595178d526e41c20cf1f09`.

The host was corrected to read the execution lifecycle's existing active-action representation, separately retain current and executing action IDs and targets, and key each measured motor outcome by a unique original-action-plus-tick attempt ID. The self-model's public API and learning rule are unchanged. A focused continued-eat regression checks these identities and that an unrelated current-choice result cannot train the attempt.

Before rerunning, this follow-up specifies independent paired reruns using original and corrected source on already studied seeds 220 and 227, under normal, always-effort and adaptive conditions. This is a six-pair reproducibility and implementation-impact diagnostic, not a fresh learning estimate. Preserve both event streams. Check equality of brain choices, actual outcomes, movements, costs and forecasts apart from new identity fields; check corrected executing action ID and target against the lifecycle outcome and unique attempt IDs. Any differences or failed attribution checks invalidate an equivalence claim.
