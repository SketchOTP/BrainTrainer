# Candidate V26: learning how much investigation to try

Status: qualified and adopted into the continuing live individual.

V25's initial investigation always permits two further trials. V26 retains actual
investigation results and uses them to allocate later investigations of the same
action across different observed types. If the first visible effect arrives on
the last allowed trial, the next budget increases by one. A no-effect result
reduces it by one. The authored bounds are two to five additional attempts.
A rehearsal carries the outcome-event references and previous/next budget values;
it does not count simulated expectations as real successes.

This changes the investigation procedure's future decisions through experience.
It is not self-written experiment-design code, proof of an optimal allocation,
or evidence of general recursive intelligence. Cross-type transfer is uncertain:
a delay in one object does not prove any other object can respond. More patience
can discover a later effect but can also waste more trials on an inert object.
Negative evidence lowers the subsequent allocation; it does not prove impossibility.

The curriculum remains the owner of the plan and projection. Completed results
are ordered by their outcome events, separated by action, and reconstructed from
history. Only V26 investigation records participate, preserving prior model
semantics. First-effect timing is taken from actual matched visible transitions.
The executable evaluator now validates the actual recorded investigation allowance
for inert cases; an arbitrary longer stopping rule without an investigation does
not qualify for a larger bound.
