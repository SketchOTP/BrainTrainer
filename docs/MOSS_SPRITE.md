# Moss sprite asset

The project asset `src/creature_brain/pet_web/moss-detailed-v1.png` was generated with the built-in image generation tool and retains a transparent background. It supplies four illustrated views of the same creature; the renderer selects a view from projected heading, mirrors the back view as needed, and adds a small grounded bob while moving. It is not a frame-by-frame walk cycle.

The character reference was generated with this prompt:

> Create a single original game creature sprite on a truly transparent background. Moss is a small nonhuman digital pet, not a person: compact stocky quadrupedal forest reptile with four short paws, soft rounded earthy green scales, subtly mossy ridge and small swept horns, curious amber eyes, long short-tailed salamander/dragon silhouette. Friendly but rugged and gender-neutral. No clothes, no tools, no accessories, no bags, no humanoid body, no text, no shadow. Beautiful detailed hand-crafted pixel art, clear clustered pixels and crisp outline, muted moss/olive/stone palette, angled 2.5D three-quarter front pose, all feet visible, centered full body, suitable as a sprite in a detailed realistic dark forest pixel-art world.

The final sheet used that image as a reference with this prompt:

> Using the referenced creature as exact character design and pixel-art style reference, create a game sprite sheet with exactly four complete, equally sized poses on a transparent background, aligned in one horizontal row with four equally spaced cells and clear gaps: left-facing side, three-quarter front, right-facing side, and back-facing three-quarter. Same single small stocky quadrupedal moss-scaled horned creature, no clothing or props. All four poses standing naturally, feet on the same baseline. Crisp pixel art, no labels, no borders, no shadow, no scenery.
