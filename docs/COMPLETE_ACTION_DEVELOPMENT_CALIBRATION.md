# CB-20261107-02 development calibration

Before fresh testing, evaluate actual brain-selected interaction from distances 1.0, 1.5 and 2.0 units, all outside the host's 0.85 contact radius. For each distance test development seeds 0–3, both mirrored directions, all four motor conditions and a 64-tick maximum. Start each calibration case from a fresh seed-matched individual, with one food presented; the environment does not name an action or target to the brain. Record every tick, original choice, lifecycle action, target, motor attempt, cost, contact and consumption; include non-completion. These development cases are not the continuing held-out individuals.

Select the distance with the highest completed-interaction count at 64 ticks across the 32 cases; tie-break in favor of the larger distance. At that distance select the shortest fixed budget among 16, 32 and 64 ticks that captures at least 80% of the observed 64-tick completions. If no case completes, do not claim a calibrated task or run a confirmatory evaluation. These rules are fixed before observing the calibration results; the later fresh-run task additionally introduces body impairment.

Qualification additionally requires at least 8 completions among all 32 scheduled cases at the chosen distance within 64 ticks; all no-choice and failed cases remain in the denominator. For budget selection, compute completion rates with denominator 32 for each budget and select the shortest whose rate reaches at least 80% of the 64-tick rate. This guards against a vacuous threshold based on a handful of successes. If the 8-of-32 floor fails, stop before the fresh evaluation and report the bottleneck.
