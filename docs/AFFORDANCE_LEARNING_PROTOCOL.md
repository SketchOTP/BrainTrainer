# Self-set affordance learning and transfer

Freeze seeds 60–63 crossed with two physical device functions: switch (state flips)
and counter (state increments). The learner sees opaque labels, present state,
position/contact and available actions, not the implementation function. Labels
are unique per seed/function; location sign is seed parity. Training device starts
2 units away. No goal, demonstration or action command is given to the creature.
Allow 24 ordinary ticks to self-select practice and demonstrate two actual state
changes. All unsuccessful cases stay in the denominator.

Hide the first device and expose a different identity with the same observable
type, 4 units away in the opposite relative direction. Fork the complete acquired
state into intact-memory and skill-projection-cleared branches. In the latter,
clear only the curriculum's derived skill projection and record the intervention;
keep brain, body, episode ledger and prior goals. This is a controlled memory-path
ablation. A normal checkpoint restore rebuilds that projection from history, so
future reproduction of the ablated condition requires the harness intervention.

Allow 24 ordinary ticks per branch, ending when the new object's learning goal is
locally demonstrated. Gates per case: training succeeds; intact memory creates a
verify-known-skill goal, accurately predicts the observed initial effect, and
requires one actual activation; cleared memory creates a discovery goal and
requires two actual activations. Compare actual outcomes and evidence, not only
goal labels. Report approach ticks and failures. These thresholds are authored
stopping rules, not statistical confidence estimates. This panel tests a useful
memory path and local transfer, not universal few-shot learning or a learned
algorithm for switches/counters beyond observed state transitions.
