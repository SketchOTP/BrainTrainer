# Outcome recall development experiment

This is a development panel, not held-out qualification. The authored adapter
learns a recency-weighted mean of observed hunger relief for an object type,
category and executed action. Only completed outcomes matching original action,
target and action ID contribute. It supplies existing noun/verb sensory inputs;
it cannot execute actions. A positive offer/outcome association can identify a
person to ask when hungry and no known helpful resource is visible. This is not
face recognition, a causal claim about a person, or an established relationship.

Before inspecting this panel, use seeds 0–3; offer alternating food identities
three times each, at contact distance, with up to 32 natural ticks per offer.
The other food and toy are hidden. The experimenter places objects; the recovered
brain chooses actions, and unsuccessful opportunities remain in the report.
History and body/brain state continue without reset. No hidden food-value field
is available to OutcomeRecall. This panel uses the existing body's fixed food
consequences; no generalization or reversal success is implied.

After acquisition, expose both foods at equal contact distance. Fork explicit
test branches from this state. The candidate adopts learned recall; the control
retains passive memory. Run 24 ticks on each, retain events and checkpoints, and
report cues, choices, outcomes and any state divergence. This comparison measures
whether the added memory path affects actual behavior for the same starting host;
it is not a learning-disabled control for the genome brain.

Software checks also cover information/hypothesis exclusion, wrong attribution,
unknown objects, changed effects, human-offer association, invalid cue rejection
before mutation, and actual process restart after recall adoption. Stronger
population qualification and free-life activity selection remain future work.


## Development revision v2

The retained v1 panel completed all 24 acquisition offers. All four recall
branches first ate the helpful food, while all four passive branches first ate
the harmful food. However, all recall branches subsequently ate the harmful food
as well. V1 is not qualified for harm avoidance; sources and checkpoints remain
under validation/recall-development-v1.

V2 adds an authored retreat cue for a nearby object whose experienced interaction
has negative mean relief, when no known helpful resource is available. The brain
still chooses its action. The distance threshold of 2 world units is a disclosed
host policy, not learned spatial competence. Reuse the same development panel;
report harmful consumption, net relief and motor reserve alongside choices.
This is development reuse after a failure, never a fresh qualification claim.


V2 did not prevent harmful consumption in any of the four histories. Its recorded
retreat cues were present before harm, but the brain continued choosing eat.
That is an observed failure of the cue path, not evidence that no memory existed.
The extra avoidance policy was rejected and removed from the working candidate;
its complete sources and evidence remain under validation/recall-development-v2.
The working candidate retains v1 positive recall and expressly does not claim harm
avoidance. Hunger-adjustment totals refer to the action feedback signal; clipping
can make them differ from actual body hunger change. Qualification must report
actual before/after body hunger separately.
