# Executable practice revision: bounded evidence

The prospective panel specified in [the protocol](EXECUTABLE_PRACTICE_PROTOCOL.md)
passed for all four seeds (81–84), with alternating contact geometry. Each
individual reached a real three-attempt stop after one visible switch change.
The next ordinary tick initiated evaluation from its own recorded review.

| Candidate executable rule | Productive test cases | Inert case | Decision |
|---|---|---|---|
| Stop at six total attempts | All five passed | Six wasted attempts; failed bound | Rejected |
| Stop after three consecutive attempts without visible progress | All five passed | Three attempts; passed bound | Retained |

The five productive cases were continuation of the stalled goal plus fresh
switch, counter, two-press switch and three-press switch. Every retained candidate
completed the stalled real goal on the next actual tick. Parent lineage and
prior event history remained identical. Test branches have distinct branch IDs,
parent checkpoint digests, explicit controls and retained raw events. Their
outcomes remain test evidence rather than the parent's lived competence.

The code change is executable Python source: the return expression changes from
`trials >= 3` to `no_change_streak >= 3`. The source is compiled, governs real
practice, is retained in implementation history, and is reconstructed after
restart. The allowed program language is finite and contains no host operations.
The adopted source digest is
`2b6f7bd45833f0849be04b24bdb24af946159f29711b1d3449e32e07593e7440`.

Evidence is in `validation/executable-practice-v1/`: protocol runner, before/after
checkpoints, generated candidate files, full evaluation records and results.
Four dedicated tests passed, including actual process restart, rejected source
and digest mismatch, no unjustified change for an entirely unresponsive object,
and unchanged continuing history. Seven existing curriculum tests and seven
existing developmental/rehearsal tests also passed. A further 25 continuity, body,
recall, inherited-preparation and action-lifecycle tests passed: 43 tests total.
All 267 original source-manifest files remain unchanged. The source and evidence
digests are recorded in `validation/development-v4-receipt.json`.

This demonstrates one kind of experience-initiated executable policy revision.
The diagnosis, source generator and evaluation design are authored. All four
cases select the same improvement; they do not establish four distinct discoveries.
It does not establish arbitrary software modification, broad regression freedom,
repeated different improvements, or improvement of the improvement mechanism.
A device whose first effect needs more than three attempts remains unresolved.
Sustained companionship, a visible integrated habitat and the full end goal remain
unqualified.
