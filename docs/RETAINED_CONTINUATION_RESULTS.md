# V20: protect recorded successful practice continuations

The fixed regression suite could accept a new practice rule that stops an older,
slower learned activity. V20 retains executable continuation inputs from actual
practice and qualifies them only when the activity later completes with observed
visible effects. Unfinished activities do not supply successful evidence. Steps
controlled by a supplied practice allowance are excluded from executable checks.
The curriculum owns these records, including their experience and completion
event references; replay restores them without inventing past experiences.

Before branch testing, each candidate rule is executed on these retained inputs.
A candidate that would stop at a recorded successful continuation is rejected.
Passing these checks does not waive any existing branch regression. Counterfactual
checks add no lived outcomes and are reported separately from branch results.

## Evidence

`validation/retained-continuations/paired-evidence.json` contains a paired rural
qualification. An intentionally injected valid uniform-bound candidate passed the
fixed eight-profile suite with retained checks disabled. With checks enabled it
was rejected at a previous five-attempt activity's recorded continuation:
trials 9, changes 1, no-change streak 4, observed gap 5. The actual completion
followed at the next experience event. Nine retained inputs were checked.
The protected evaluator instead selected the gap-sensitive margin-two rule,
which passed every required profile. Evaluating either candidate left the source
individual unchanged. No test experiences were merged into the live companion.

Five retained-continuation/timing tests passed in 59.110 seconds. Three upgrade
and counterfactual regression tests passed in 17.364 seconds. Tests cover exact
restoration of retained checks and exclusion of incomplete activities. A live
checkpoint preflight at tick 12815 preserved host state, lineage, all prior
events, and exact snapshot restoration.

## Limits

This protects specific recorded continuation decisions, not every acquired
ability or every future context. A historical continuation can become unsuitable
when conditions change; this conservative gate has no evidence-retirement policy
yet. The environment and deliberately regressive candidate were arranged for
qualification. The evaluator and finite executable language remain authored.
V20 begins collecting evidence after adoption, rather than retrospectively
attributing new knowledge to the continuing individual.

This was desktop browser observation through the Tailscale URL, not physical
phone acceptance.
