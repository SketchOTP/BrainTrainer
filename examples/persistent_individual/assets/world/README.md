# World asset pack

The renderer is included in this folder. The local development copy also uses map JSON and atlas images produced from a Porymap project based on Pokémon Emerald/Littleroot. Those ROM-derived files and the Pory project are not redistributed in this public repository.

To run the top-down habitat, provide an asset pack you are authorized to use with the filenames and map schema expected by `examples/persistent_individual/world_body.py`. Until then, the top-down habitat world is source-only in this public checkout.
